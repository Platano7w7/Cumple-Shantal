Quiero que diseñes una experiencia web de cumpleaños única y emocional para una amiga llamada Shantal que cumple 21 años.

IMPORTANTE:

La página será desarrollada posteriormente usando HTML, CSS y JavaScript puro (Vanilla JS).

NO utilices React, Next.js, Vue, Angular, Tailwind, TypeScript ni ningún framework.

Diseña todas las vistas, secciones, animaciones e interacciones pensando en que sean fáciles de implementar usando únicamente HTML, CSS y JavaScript.

Describe visualmente cada pantalla, su estructura, ubicación de elementos, animaciones, transiciones y comportamientos interactivos.

La experiencia debe sentirse como una carta interactiva, una sorpresa de cumpleaños y una pequeña aventura personalizada.

PANTALLA DE INICIO

La pantalla inicial debe ser minimalista.

En el centro aparece una caja de regalo rosada brillante.

NO usar un corazón.

La caja debe tener:

- Brillo rosado.
- Sombra neón.
- Animación de flotación.
- Pequeño movimiento suave.

Debajo mostrar:

"Presiona para abrir tu regalo 🎁"

Al pasar el cursor:

- La caja aumenta ligeramente de tamaño.
- El brillo aumenta.

Al hacer clic:

- La caja se abre.
- Sale disparada hacia arriba.
- Explota en partículas.
- Aparece una lluvia de confeti rosado, negro y dorado.
- La cámara realiza una transición suave hacia la experiencia principal.

La animación debe sentirse especial e inolvidable.

--------------------------------------------------

TRANSICIÓN

Las partículas comienzan a moverse por toda la pantalla.
